# Tailwind Starter

A small responsive HTML/CSS landing page using Tailwind CSS via the browser CDN.

## Run it

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
npx serve .
```

Edit `index.html` for the page structure and utility classes. Add project-specific styles to `styles.css`.

> The CDN setup is ideal for prototyping. For production, install Tailwind locally and compile a CSS build.
